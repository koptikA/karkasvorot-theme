# karkasvorot.by: новый сайт

Классическая WordPress-тема `karkasvorot` для мастерской металлоконструкций в Минске и Минской области. Мастерская делает каркасы откатных и распашных ворот, калитки, а также прочие изделия: мебель, обувницы, заборы, навесы. Тема заменяет одностраничный лендинг. Цели — заявки из органического поиска (Яндекс, Google) и соответствие законам РБ. Хостинг — hoster.by, Минск.

## Команды

| Команда | Что делает |
|---|---|
| `KV_PORT=9425 bash tools/serve.sh` (Git Bash, в фоне, ждать «Ready!») | Локальный WordPress Playground: PHP 7.4, тема примонтирована вживую, сайт каждый раз собирается с нуля; вход `admin`/`password` |
| `python tools/check_site.py http://127.0.0.1:9425` | Все проверки из `tools/checks/*.py`; с `KV_LIGHTHOUSE=1` — ещё и Lighthouse |
| `python tools/stand.py php '<код>' --base http://127.0.0.1:9425` | Выполнить PHP на стенде |
| `python tools/build_zip.py [--install <url чистого стенда>]` | Собрать `dist/karkasvorot.zip`; с `--install` — заодно проверить установку |

## Устройство

- `theme/karkasvorot/inc/`:
  - `settings.php` — Customizer и `kv_opt()`;
  - `content-model.php` — типы `work` и `lead`, метаполя услуг;
  - `installer.php` — `kv_install()` на `after_switch_theme`: создаёт страницы, меню и работы, переводит старые слайды в черновики, ничего не удаляет;
  - `leads.php` — форма и заявки, PRG, ловушка для ботов, cookie-секрет для ошибок;
  - `seo.php` — title, description, canonical, OG, JSON-LD, robots, sitemap, редиректы. Если стоит Yoast или Rank Math, тема свои SEO-теги не выводит.
- Контракт модулей — `.autopilot/2026-11-09-karkasvorot-site--wip/interfaces.md`.
- Документы:
  - `docs/zapusk.md` — запуск, для владельца;
  - `docs/dizain-brif.md` и `docs/oformlenie.md` — дизайн;
  - `docs/katalog.md` — цены и иллюстрации;
  - `docs/proverka-05.md` — приёмка.

## Правила

- Только синтаксис PHP 7.4. Без плагинов и без сборки. Префикс `kv_`. Проверки пишутся только на stdlib Python.
- **Числовые цены публично не показываются** (решение владельца). Поля цен остаются в админке, но не выводятся ни в карточках, ни в title, ни в JSON-LD.
- Факты о бизнесе не выдумывать. Пока пусты: реквизиты (наименование, УНП, адрес), e-mail, часы, ID Метрики.
- Фото работ — только реальные. Сгенерированы только иллюстрации-чертежи карточек.
- Боевой сайт менять только по прямой команде владельца. Пароль администратора нигде не сохранять.
- `git config core.autocrlf false` — окончания строк не трогать.
