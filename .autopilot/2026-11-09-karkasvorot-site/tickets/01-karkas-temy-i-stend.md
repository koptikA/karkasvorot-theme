**Требования:** R04, R07, R09i, R14i, R16i, R12i.6, R13i, R06 (доступность базовых шаблонов)
**Blocked by:** —
**Зона:** `theme/karkasvorot/` (всё, кроме файлов других тасков), `tools/` (стенд, раннер, `tools/checks/base.py`), `tools/fixtures/`
**Волна:** 1
**Status:** ready

## Что должно заработать

Локальный WordPress на Playground поднимается одной командой, в нём установлена и активна тема `karkasvorot`, в медиатеке лежат фикстуры — те же файлы с теми же alt, что на боевом сайте. Тема даёт шапку и подвал (контакты, зона работы, реквизиты из настроек), базовые шаблоны, настройки в Customizer, типы записей «Работы» и «Заявки», метаполя услуг и работ. Остальные таски строят на этом.

Решение; Решения по реализации; Данные и контент (контакты, цены, работы — только как значения по умолчанию/фикстуры); Границы и швы; `interfaces.md` целиком — это контракт.

## Состав

- `style.css` (заголовок темы: Requires PHP 7.4, Requires at least 6.4), `functions.php` (подключает `inc/*.php`; `inc/installer.php`, `inc/leads.php`, `inc/seo.php` создать **заглушками** с функциями из interfaces.md, возвращающими пустое — их наполнят таски 02, 03, 04), `inc/settings.php`, `inc/content-model.php`.
- Шаблоны: `header.php`, `footer.php`, `index.php`, `page.php`, `single.php`, `archive.php`, `404.php`, `search.php`, `page-service.php` (минимальный: h1 + контент; полный — таск 02).
- Шапка: логотип-текст KARKASVOROT.BY → `/`, меню (location `primary`), телефон (`data-goal="phone_click"`), Viber (`viber_click`), Telegram (`telegram_click`), «Минск и Минская область». На мобильном — закреплённая нижняя панель: Позвонить / Viber / Telegram / Заявка (`#zayavka`). Ссылка «Перейти к содержимому». Меню-бургер на мобильном (`assets/site.js`, без jQuery).
- Подвал: «Минск и Минская область, доставка каркасов по Беларуси», контакты, реквизиты (наименование, УНП, адрес, регистрация, e-mail) — пустое поле посетителю не выводится; залогиненному админу на его месте видна плашка «Заполните: Внешний вид → Настроить → Реквизиты» (`kv_is_placeholder`). Ссылка на политику ПД. Без шаблонного «со ссылкой на источник: URL».
- `<body data-metrika="…">` из настроек (пусто → пустой атрибут).
- `assets/site.css`: токены в `:root` (белый фон, графит, акцент `#42a9ed`, Manrope + системный стек), базовая типографика, контейнер, шапка/подвал/мобильная панель, видимый `:focus-visible`, контраст AA. `assets/fonts/` — Manrope woff2 кириллица 400/700 (официальный источник, лицензия OFL — положить `OFL.txt`).
- `add_theme_support`: `title-tag`, `post-thumbnails`, `html5`, `responsive-embeds`; размеры картинок под карточки; фильтр `image_editor_output_format` jpeg/png → webp.
- Стенд: `tools/serve.(py|sh)` + blueprint: Playground с примонтированной темой, постоянные ссылки `/%postname%/`, админ-логин, импорт фикстур (файлы с `https://karkasvorot.by/wp-content/uploads/...` — список и alt из REST `https://karkasvorot.by/index.php?rest_route=/wp/v2/media&per_page=100`; скачать один раз в `tools/fixtures/uploads/`, alt и заголовки в `tools/fixtures/media.json`), затем активация темы (чтобы `after_switch_theme` сработал после импорта). Плюс в стенд добавить записи-«слайды» с пустыми заголовками и с заголовками «Слайд2», «Слайд4», и страницу «Пример страницы» (slug `sample-page`) — как на боевом (для проверки черновиков в таске 02).
- `tools/check_site.py` (раннер, stdlib) + `tools/checks/base.py`: главная 200; шапка содержит `tel:+375447726823`, viber, telegram, «Минск»; ссылка «к содержимому»; в подвале нет «источник: URL»; `<html lang="ru-RU">` или `ru`; PHP-ошибок/notice/warning в HTML нет.
- `tools/README.md`: как поднять стенд, как прогнать проверки, как пересобрать с нуля, как выполнить PHP/WP-код на стенде (нужно тестам 02–04).
- `.gitignore`: не коммитить временные файлы Playground; фикстуры коммитить.

## Критерии приёмки

- [ ] Стенд поднимается одной командой из README, тема активна, фикстуры в медиатеке с alt как на боевом
- [ ] `python tools/check_site.py http://127.0.0.1:9400` — зелёный
- [ ] Customizer: секции «Контакты», «Реквизиты», «Аналитика» со всеми ключами из interfaces.md; контакты по умолчанию со старого сайта
- [ ] Типы `work` (публичный, архив `nashi-raboty`) и `lead` (не публичный, без REST, только `manage_options`) зарегистрированы; метабоксы услуги и работы сохраняют поля
- [ ] Заглушки `kv_install`, `kv_order_form`, `kv_breadcrumbs`, `kv_seo_plugin_active` существуют и не падают
- [ ] Код совместим с PHP 7.4 (без синтаксиса 8.x)
